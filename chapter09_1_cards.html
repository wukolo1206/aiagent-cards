真實行政痛點

學校/機構公文整理的四大魔王困境

傳統公文下載後，檔名無意義、附件失聯，整理耗費大量重複體力。

❌ 檔名亂碼難辨識
如 115E0004465.pdf 根本不知何事
❌ 附件與主文失聯
1574799_附件1 找不到發文函
❌ 日期與會議未標
開會時間隱藏在說明第二段
❌ 手動登錄極耗時
後續幾十份公文重複貼Excel

Skill 解法思維

什麼是 Custom Skill？為何超越寫死指令？

Skill 就像給 AI Agent 裝上專業 SOP 技能包，讓 AI 能根據情境自動觸發並精準執行。

傳統做法 (Hardcode)

寫死單次 Python 程式，每次換資料夾或換公文就得重新改程式碼或手動執行。

Custom Skill 模式

SOP 固化

封裝成 SKILL.md，只要使用者說「整理公文」，AI 自動調用工具完成全套 SOP！

Skill 結構剖析

official-doc-organizer / SKILL.md 核心架構

包含 Frontmatter 元資料（觸發時機）與 4 步驟標準作業程序 (SOP)。

---
name: official-doc-organizer
description: Use this skill whenever user wants to organize official PDFs...
triggers: ["整理公文", "公文標日期", "產生公文清單"]
---
# 核心流程 (SOP)
1. 掃描與解析 PDF 內文 (日期/字號/主旨/會議)
2. 語意化重新命名 [YYMMDD]_[公文/附件]_[標題].pdf
3. 自動更新格式化 Excel 試算表
4. 自動生成/更新 Markdown 索引超連結

SOP 工作流程

Skill 的四大自動化階段

從混亂的原始檔案，到乾淨語意化的檔名與雙系統清單更新。

1. 掃描解析 提取日期/字號/主旨
2. 語意命名 YYMMDD_公文/附件
3. Excel 同步 深藍表頭與資訊格
4. MD 索引 雙向超連結建立
